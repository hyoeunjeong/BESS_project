> 태양광 연계 **BESS(Battery Energy Storage System, 배터리 에너지 저장장치)**를
> **규칙 기반 · LSTM · GRU** 세 가지 방식으로 제어·시뮬레이션하고,
> **경제성 · 에너지 효율 · 운영 안정성 · 예측 정확도**를 다각도로 비교하는 학사학위논문 코드베이스입니다.

한국전력거래소(SMP)·공공데이터포털(부하)·기상청(일사량) **2025년 실측 1년치(8,760시간)** 데이터를 사용하며,
세 방식이 **동일한 데이터·동일한 제어 정책**을 쓰고 **예측기만 다르도록** 설계해 공정하게 비교합니다.

## 1. 연구 배경과 질문

### 1.1 배경

탄소중립과 분산형 전원 확대로 태양광 발전 비중이 빠르게 늘고 있으나, 태양광은 일사량·기상에 따라
출력 변동성이 크다. 태양광이 집중되는 **주간**과 수요가 높은 **저녁 피크** 사이의 시간적 불일치는
**순부하(net load = 전력 수요 − 태양광 발전량)** 곡선을 낮에 급감했다가 저녁에 급증하는
**덕 커브(duck curve)** 형태로 만들며, 발전기의 급격한 출력 조정(ramping)과 계통 운영 부담을 유발한다.
태양광 비중이 높은 지역에서는 공급 과잉에 따른 **출력제한(curtailment)** 손실도 발생한다.
또한 국내 산업용 요금 체계는 여름철 주간이 최대부하 구간이라 **태양광 발전 시간대와 고요금 시간대가
부분적으로 중첩**되어, 저장뿐 아니라 발전 시간대 내 충·방전 판단도 운영 성과를 좌우한다.

### 1.2 필요성 — BESS와 운영 알고리즘

**BESS(Battery Energy Storage System)**는 잉여 전력을 저장했다가 필요 시점에 방전해 태양광 변동성을
완화한다. 에너지 아비트리지(요금 차익), 부하 이전(load shifting), 피크 저감 등을 수행하는 핵심 수단이지만,
**언제 충·방전할지를 결정하는 운영 알고리즘**에 따라 동일 용량이라도 요금 절감·피크 저감·활용률에서
큰 성과 차이가 난다. 따라서 하드웨어 성능뿐 아니라 **충·방전 시점 결정 전략의 설계**가 시스템 효율을 좌우한다.

### 1.3 기존 방식의 한계

기존 BESS 운전은 주로 **규칙 기반(rule-based)** 제어에 의존한다. 구현이 단순·안정적이지만,
**미래를 예측하지 않고** 현재 시점·사전 정의된 시간대에만 의존해 의사결정하므로 부하·발전량의 급변에
유연하게 대응하지 못한다. 실제 값이 예상과 다르면 상황에 맞지 않는 충·방전을 내려 배터리를 비효율적으로
운용하거나, 정작 필요한 시점에 저장 여유/방전 용량을 확보하지 못한다. 계절·요일·기상에 따른 패턴 다양성도
반영하기 어려워 확장성·적응성에 한계가 있다.

### 1.4 목적과 연구 질문

본 프로젝트는 **딥러닝으로 순부하를 예측**하고 그 예측으로 BESS 충·방전 전략을 수립하여, 규칙 기반과의
운영 성능을 정량 비교한다. 운영 성능은 요금 절감이라는 단일 관점이 아니라 **(Ⅰ) 경제적 효율, (Ⅱ) 에너지
효율, (Ⅲ) 운영 안정성**의 세 관점에서 종합 평가하며, 특히 **예측 정확도의 향상이 실제 운영 성과로
이어지는지, 그렇지 않다면 그 원인은 무엇인지**를 규명하는 데 초점을 둔다. 순부하 예측에 널리 쓰이는
**LSTM·GRU** 두 모델을 규칙 기반과 함께 비교한다.

- **Q1.** 순부하 예측에서 LSTM과 GRU의 예측 성능은 어떤 차이를 보이는가.
- **Q2. [경제적 효율]** 예측 기반 운영은 규칙 기반 대비 전력요금 절감·피크 대응에서 어떤 차이를 보이며, 그 차이는 무엇에서 비롯되는가.
- **Q3. [에너지 효율·운영 안정성]** 예측 기반 운영은 충·방전 효율과 SOC 안정성에서 규칙 기반과 어떤 차이를 보이는가.

> 본 저장소는 이 질문들을 실제 시계열 데이터 기반 시뮬레이션으로 검증하여, 딥러닝 예측이 실제 BESS 운영
> 성능에 미치는 영향을 실증적으로 확인한다.

## 4. 제어 방식

### 4.1 규칙 기반 (Rule-Based)

단순 TOU(시간대별 요금) 차익거래 규칙:
1. 태양광 잉여(순부하<0) → 충전
2. 순부하>0 이고 중간/최대부하 시간 → 방전
3. 경부하 시간 + 대기 → 계통에서 충전

→ SOC를 10~90% 풀스윙하며 공격적으로 차익거래.

### 4.2 예측 기반 (LSTM · GRU)

**예측 모델** — Stacked (LSTM|GRU) 2층 · hidden 128 · dropout 0.2 · Adam(lr 1e-3) · MSE ·
Early Stopping(patience 10) · ReduceLROnPlateau · grad clip 1.0 · **시드 42 고정**.
두 모델은 구조가 동일하고 순환 셀(LSTM↔GRU)만 다릅니다.

**제어기** — 우선순위 기반(P0→P3). LSTM·GRU가 **완전히 동일한 제어 로직**을 쓰고 예측값만 다릅니다.

| 우선순위 | 조건 | 동작 |
|---|---|---|
| P0 | SOC 위험(하한/상한 근접) | 비상 충전/방전 |
| P1 | 실측 태양광 잉여 | 잉여만큼 충전 (커튼일먼트 방지) |
| P2 | 예측 순부하 > 피크 임계값 | 피크 컷 방전 |
| P3 | 그 외 | 시간대별 SOC 목표 추종(경0.80/중0.60/최0.20) |

**제어기 정정 사항** (논문의 방법론적 기여, LSTM·GRU 동일 적용):

- **(가) 역송 방지** — 모든 방전 상한을 실측 순부하 `max(부하−PV,0)`로 제한 → 계통 역송 0
- **(나) SOC 진동 제거** — 경부하 목표 0.90→0.80 (비상 임계 0.85와의 간섭 제거)
- **(다) 조건부 충전 → (#3) 경부하 전용 충전** — 비싼 중간/최대부하 계통 충전 전면 금지
- **(라) 충전 오버슈트 클램프** — SOC가 목표를 넘어 상승하는 진동 억제
- **(마) 데이터 누수 차단** — 피크 임계값을 **학습 구간(앞 70%)** 부하로만 산출
- **태양광 우선 흡수** — P1을 예측이 아닌 **실측 잉여** 기준으로 충전 → 커튼일먼트 최소화

## 5. 전력요금 체계 (TARIFF_MODE)

`config.py`의 `TARIFF_MODE` 한 줄로 두 요금 체계를 전환합니다.

### `'paper'` — 연중 단일 (논문 본문 재현용 옵션)

| 시간대 | 시각 | 단가 |
|---|---|---|
| 최대부하 | 10·11·13·14·15·16시 | 180 원/kWh |
| 중간부하 | 9·12·17~22시 | 110 원/kWh |
| 경부하 | 그 외 | 60 원/kWh |

### `'seasonal'` — 계절별 (실제 산업용(갑)Ⅱ 고압A, **기본값**)

| 계절 | 경/중/최 (원/kWh) | 최대부하 시각 |
|---|---|---|
| 여름(6~8월) | 90.8 / 116.6 / 150.1 | 15~20시 |
| 봄·가을 | 90.8 / 95.6 / 114.8 | 15~20시 |
| 겨울(11~2월) | 98.2 / 115.1 / 144.5 | 9~11·16~18시 |

> `paper`는 최대부하가 **낮**(태양광과 겹침), `seasonal`은 **저녁**(태양광 없음)이라 결과가 크게 달라집니다(§10.2).

기본요금은 최대수요전력 기준 `BASE_CHARGE_WON_PER_KW = 7470` 원/kW·월.

## 6. 평가 지표

`evaluator.py`가 산출하는 지표 (논문 표 대응).

**경제적 효율**
- `요금 절감률` / `절감액` — 무제어 대비 전력량요금 절감
- `최대부하 절감률` — 최고 요금대 절감
- `최대수요전력 저감률` — 계통 순시 최대전력 변화(기본요금 영향)
- `기본요금 증감` / `순 절감액` — 요금 절감에서 기본요금 증가를 차감

**에너지 효율**
- `태양광 이용률` · `커튼일먼트` — 태양광 활용/낭비
- `BESS 활용률` · `자립률` · `라운드트립 효율` · `BESS 기인 역송`

**운영 안정성 · 수명**
- `SOC 권장구간(20~80%) 체류율` · `SOC>80%` · `SOC<20% 심방전`
- `배터리 사이클 수` · `일일 전환 빈도` · `과충·과방전 횟수`

**예측 정확도** (LSTM·GRU)
- `MAE` · `RMSE` · `상대오차(정규화 MAE)`


## 11. 주요 발견과 결론

- **예측 기반이 경제성·안정성 전반에서 규칙 기반을 앞선다** — 순절감 GRU 400,442 / LSTM 398,281원 vs 규칙 285,497원(+40%). SOC 안정성·배터리 수명도 예측 기반 우위.
- **LSTM vs GRU** — 예측 정확도는 LSTM 근소 우위(test MAE 1.290 < 1.306)지만 경제 성과는 GRU 근소 우위(400,442 > 398,281). **예측 정확도 = 운영 성과가 아니다.**
- **수요전력 관리 계층(§4)** — 실측 순부하 기반 상한 관리로 요금적용전력을 71.24 → 70.48 kW로 낮춰 기본요금을 연 67,259원 절감(규칙기반 0원).
- **트레이드오프** — 규칙기반은 공격적 풀스윙(심방전 38.7%, 사이클 243)으로 총처리에너지는 크지만 배터리를 태우고, 예측 기반은 보수적 운용(심방전 7.9%, 사이클 186)으로 수명을 아낀다.
