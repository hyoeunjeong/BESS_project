# 딥러닝 기반 순부하 예측을 활용한 BESS 운영 성능 분석

> 태양광 연계 BESS(배터리 에너지저장장치)의 **순부하(net load)를 LSTM·GRU로 예측**하고,
> 그 예측을 충·방전 제어에 결합했을 때의 운영 성능을 **규칙 기반(Rule-Based) 방식과 동일한 조건에서
> 정량 비교**한 학위논문의 코드·데이터 저장소입니다.



---

## 1. 한눈에 보기

- **문제**: 태양광 발전은 변동성이 커 계통 운영을 어렵게 한다. BESS가 이를 완화하지만, 기존 **규칙 기반
  제어는 고정 규칙에 의존**해 부하·발전 변화에 유연하게 대응하지 못한다.
- **접근**: 과거 24시간 데이터로 **다음 1시간의 순부하(부하 − 태양광)를 예측**(LSTM·GRU)하고, 이를
  BESS 충·방전 결정에 결합한다. 규칙 기반과 **같은 데이터·같은 BESS 사양·같은 제약**에서 비교한다.
- **평가**: (Ⅰ) 경제적 효율 · (Ⅱ) 에너지 효율 · (Ⅲ) 운영 안정성 세 관점.
- **핵심 결론**:
  1. 예측 기반이 세 평가축 **모두에서 규칙 기반을 앞선다**(순 절감액 약 **40%** 우위).
  2. 그러나 그 우위의 대부분은 **예측 정확도가 아니라 예측을 제어에 결합하는 “구조”**에서 나온다
     (무예측 제어기만으로도 규칙 기반을 14.7% 앞섬).
  3. LSTM과 GRU의 예측 정확도는 **통계적으로 구분되지 않는다**(Welch p = 0.299).

### 대표 수치 (2025년 시행 요금, 8,736시점)

| 지표 | Rule-Based | LSTM | GRU |
|---|---|---|---|
| 순 절감액(원/년) | 285,497 | **398,281** | **400,442** |
| 전력량요금 절감률 | 0.75% | 0.87% | 0.87% |
| 최대부하 시간대 절감률 | 9.79% | **16.57%** | 16.58% |
| 요금적용전력(무제어 71.24kW→) | 71.24(변화 없음) | **70.48** | 70.48 |
| 배터리 사이클/년 | 243.4 | **186.2** | 188.0 |
| SOC 권장구간(20~80%) 체류율 | 15.77% | **88.83%** | 88.28% |
| 테스트 MAE(kW) | — | 1.290 | 1.306 |

## 2. 연구 배경과 질문

기존 BESS 운영은 주로 규칙 기반 제어에 의존해 왔다. 구현이 단순하고 안정적이지만, 사전에 정의된
고정 규칙에 따라 동작하므로 부하·발전량의 급격한 변화에 유연하게 대응하지 못하고, 배터리 활용률과
제어 정확도 측면에서 개선의 여지가 있다. 이에 본 연구는 **딥러닝으로 순부하를 예측하고 그 결과를
BESS 제어에 결합**했을 때 운영 성능이 어떻게 달라지는지를 정량 분석한다.

**연구 질문**
- **Q1 (예측 성능)** LSTM과 GRU는 순부하 예측에서 얼마나 정확하며, 서로 유의한 차이가 있는가?
- **Q2 (경제적 효율)** 예측 기반 제어는 규칙 기반 대비 요금을 얼마나 절감하는가? 그 원천은 무엇인가?
- **Q3 (에너지 효율·운영 안정성)** 배터리 수명(사이클)·SOC 안정성 측면의 차이는 어떠한가?

## 3. 방법론

### 3.1 데이터 (2025-01-01 ~ 12-31, 시간 단위)

| 계열 | 출처 | 처리 |
|---|---|---|
| 전력 부하 | 한국전력거래소(KPX) 시간별 전국 전력수요 | 연평균 **50kW**로 스케일 |
| 계통한계가격(SMP) | KPX SMP(**육지**) | 예측 입력 feature |
| 태양광 발전량 | 기상청 ASOS **일사량(icsr)** 기반 **추정** | `solar_kw = icsr × 50kW × 0.2778` (0~50kW) |

- 세 계열 각 **8,760시점, 결측 0**. 태양광은 실측 발전량이 아니라 일사량 기반 추정이며,
  성능비(PR)·인버터 효율·온도 보정은 미반영이다(발전량이 다소 과대평가됨).

### 3.2 BESS 사양·제약

| 항목 | 값 |
|---|---|
| 용량 / 최대출력 | 100 kWh / 25 kW |
| 왕복 효율(η) | 0.95 (왕복 90.25%) |
| SOC 운용범위 | 0.10 ~ 0.90 |
| PV 설비 용량 | 50 kW |
| 계약전력 / 기본요금 | 100 kW / 7,470 원·kW·월 |

### 3.3 순부하 예측 모델 (LSTM · GRU)

과거 **24시간**을 입력받아 **다음 1시간의 순부하**를 예측한다.

| 설정 | 값 | | 모델 규모 | LSTM | GRU |
|---|---|---|---|---|---|
| 은닉 차원 | 128 | | 학습 파라미터 | 204,929 | 153,729 |
| 층 수 | 2 | | (LSTM 대비) | 100% | **75.0%** |
| 드롭아웃 | 0.2 | | | | |
| 시퀀스 길이 | 24 | | 시드 | 42(정본) + 5시드 반복 | |

> **입력 시퀀스 24시간을 소모**하므로 예측·시뮬레이션 구간은 8,760 → **8,736시점**이 된다.
> Rule-Based 단독 실행은 8,760이며, 세 방식 비교는 timestamp 교집합 **8,736**으로 정렬한다.

### 3.4 제어 방식

- **규칙 기반(Rule-Based)**: ① 경부하 충전 ② 고요금 시간대 방전 ③ 잉여 태양광 충전의 고정 규칙.
- **예측 기반(LSTM·GRU)**: 아래 5개 계층으로 구성된 제어기. **예측값은 P2(peak_cut) 한 계층에서만
  직접 사용**되며, 실제 예측 참조 비율은 전체 시점의 1.4~2.2%에 불과하다.

| 계층 | 역할 | 예측 사용 |
|---|---|---|
| **P0′** | 수요전력 관리(요금적용전력이 목표 P_tgt 초과 시 억제, κ=0.90) | — |
| **P0** | 비상 보호(과방전/과충전 방지) | — |
| **P1** | 잉여 태양광 충전 | — |
| **P2** | 피크 절감(예측 순부하가 임계 초과 시 방전) | **사용** |
| **P3** | 시간대별 SOC 목표 추종(경부하 80%·중간 60%·최대 20%) | — |

### 3.5 제어기 정정 6단계 (A → F)

본 연구의 방법론적 특징은 제어기를 완성형으로 제시하지 않고, 초기 설계의 결함 6가지를 **단계적으로
정정하며 각 정정의 기여도를 분리 측정**한 데 있다.

| 단계 | 정정 내용 |
|---|---|
| (i) | 방전 상한에 태양광을 차감(순부하 기준) |
| (ii) | 경부하 SOC 목표를 비상 임계값 아래로 조정(계층 간 간섭 제거) |
| (iii) | 중간부하 무조건 SOC 추종 → 고가 전력 구매 억제 |
| (iv) | SOC 목표 추종 충전의 오버슈트 클램프 |
| (v) | 피크 임계값을 **학습 구간에서만** 산출(미래 정보 누수 차단) |
| (vi) | 충전 전력에 계통 측 상한 부여 + **P0′ 수요전력 관리 계층 신설** |

### 3.6 요금 체계·평가

- 한국전력공사 **산업용(갑)Ⅱ 고압A 선택Ⅱ**, **2025년 시행** 계절별 시간대·단가(토·공휴일 계량 반영).
- 경제성(전력량요금·기본요금) / 에너지 효율(사이클·커튼일먼트) / 운영 안정성(SOC 체류·심방전)으로 평가.

## 4. 주요 결과

### 4.1 예측 성능 (표2.7) — 두 모델은 통계적으로 동급

| 구간 | LSTM | GRU |
|---|---|---|
| 테스트 MAE (시드 42) | 1.290 kW | 1.306 kW |
| 테스트 MAE (5시드 평균±σ) | 1.203 ± 0.066 | 1.283 ± 0.142 |
| 전체 구간 MAE (학습 포함) | 1.979 | 1.701 |

→ 5시드 반복에서 **Welch t = −1.14, p = 0.299**로 유의한 차이 없음. 다만 시드 간 변동은 GRU가
2.15배 크고, 파라미터는 GRU가 25% 적다. **평균 정확도는 동급, 재현 안정성은 LSTM·연산 효율은 GRU** 우위.

### 4.2 운영 성능 (표2.8) — 세 축 모두 예측 기반 우위

- 순 절감액 **RB 285,497 → LSTM 398,281 / GRU 400,442원**(약 40% 차이).
- 요금적용전력을 71.24 → **70.48kW**로 낮춰 기본요금 **연 67,259원** 절감(규칙 기반은 변화 없음).
- 사이클 243.4 → **186.2회**(23.5%↓), SOC 권장구간 체류 15.77 → **88.83%**(5.6배).

### 4.3 방전 배분의 차이 (표2.9·2.10)

| | 규칙 기반 | 예측 기반 |
|---|---|---|
| 총 방전량 중 **중간부하** 소진 | **77.6%** | 34.3% |
| 총 방전량 중 **최대부하**(고단가) 투입 | 22.4% | **65.0%** |

→ 규칙 기반은 먼저 도래하는 중간부하에서 에너지를 소진하는 반면, 예측 기반은 SOC 목표 관리로
**최대부하까지 에너지를 이월**한다. “더 많이”가 아니라 **“더 정확한 시점에”** 쓰는 것이 성과를 좌우한다.

### 4.4 우위의 원천 — 예측이 아니라 제어 구조 (표2.14, 절제 실험)

동일 제어 구조에 예측 소스만 바꾼 절제 실험:

| 예측 소스 | 테스트 MAE | 순 절감액 | 완전예측 상한 달성률 |
|---|---|---|---|
| 무예측(no-pred) | — | 460,192(전력량 327,477) | — |
| 일간 지속성(t−24) | 5.06 | 528,211 | **79.6%** |
| LSTM | 1.290 | 398,281 | 20.4% |
| GRU | 1.306 | 400,442 | 32.8% |
| 완전예측(상한) | 0.00 | — | 100% |

→ **무예측 제어기만으로도 규칙 기반을 14.7% 앞서며**, 예측 소스 교체의 추가 기여는 최대 5% 수준.
정확도와 절감이 단조 관계가 아니어서(일간 지속성이 LSTM보다 절감이 큼), 우위의 본질은 **제어 구조**다.

### 4.5 계절별 절감률 (표2.13) — 겨울엔 규칙 기반이 우세

| 계절 | Rule-Based | LSTM | GRU |
|---|---|---|---|
| 여름 (6~8월) | 0.996 | 1.292 | 1.292 |
| 봄·가을 | 0.071 | 0.557 | 0.560 |
| 겨울 (11~2월) | **1.189** | 0.842 | 0.855 |

→ 봄·가을은 예측 기반이 규칙 기반의 약 7.8배. 반면 **겨울은 규칙 기반이 우세** — 최대부하 구간이
하루 두 차례로 분할되어 저장 에너지의 기간 간 배분 문제가 생기는데, 단일 시점(1시간) 예측으로는 이를
해결할 수 없기 때문이다.

### 4.6 민감도 (표2.15·2.16)

- **저감 계수 κ**: 0.85 / 0.90(채택) / 0.95 → 순 절감 418,336 / 398,281 / 587,790원. 사후적으로는
  κ=0.95가 우수하나, 결과 관측 전 설계값 κ=0.90을 유지(사후 최적화 회피).
- **2026 개편 요금**: 최대부하 시간대가 저녁으로 확대되면 기본요금 절감 여지가 사라져(ΔC_base = 0),
  규칙 기반 대비 순 절감 우위가 약 **40% → 20%**로 축소된다.

> **[필수] UTF-8 콘솔**: 스크립트가 한국어를 출력하므로 한국어 Windows(cp949) 콘솔에서는
> `UnicodeEncodeError`가 난다. 실행 전 아래를 설정한다.
> `PowerShell: $env:PYTHONUTF8=1` · `cmd: set PYTHONUTF8=1` · `bash: export PYTHONUTF8=1`

### 6.1 데이터 준비 (최초 1회)

**KPX/ASOS 원자료는 보안상 저장소에 포함하지 않는다.** 프로젝트 루트에 `.env`를 만들고 공공데이터포털
인증키를 넣은 뒤, 각 `main.py`를 `USE_*_API=True`(기본값)로 최초 실행하면 캐시가 생성된다.

```
COMMON_API_KEY=발급받은_인증키
```

## 8. 알려진 한계 (논문 §2.4.2·§3 기재)

- **태양광 과대평가**: 일사량 기반 추정이라 PR·인버터 효율·온도 보정 미반영(약 20% 과대).
- **평가 구간이 학습 구간을 포함**(in-sample): 전체 구간 오차는 일반화 성능이 아니므로 테스트 구간으로 판단.
- **단일 시점(1시간) 예측**: 겨울철처럼 최대부하가 분할되는 다중기간 배분 문제는 해결하지 못함.
- **단일 사이트·1년·단일 요금 체계** 시뮬레이션 — 일반화에는 추가 검증 필요.
- 절감률의 절대 수준은 두 방식 모두 1% 미만으로, 현행 요금 구조에서 소규모 BESS의 경제성은 제한적.
